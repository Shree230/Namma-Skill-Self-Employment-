# Namma-Skill-Self-Employment-

Namma-Skill – Training Opportunity Tracker

Project Type
Android App Development using GenAI – Self Employment

Problem Statement
There are many government skill development centers, but youth in small towns often do not know when a short-term batch such as welding, mobile repair, sewing, electrician, or coding starts. Because of this, they miss training opportunities and remain unemployed.

Vision
Namma-Skill acts as a bridge between skill centers and rural youth. It lists upcoming vocational courses, eligibility, duration, and job guarantee status. Users can apply with one click by sending their basic profile to the training center.

Main Features
*Course Finder with filters
*Filter by Short Term and Long Term duration
Center Map placeholder
Success Stories section
Interest Ping / callback request concept
Apply button with Candidate Summary generation
AI Chat Assistant
AI Course Recommendation placeholder
Smart notification concept
Technology Stack
Kotlin
Jetpack Compose
Firebase Firestore placeholder
Firebase Cloud Messaging placeholder
Google Maps API placeholder
GenAI helper module
Success Criteria
App allows filtering by duration.
Apply button generates a candidate summary.
UI is professional and aspirational.
GenAI features support recommendation and chatbot functionality.

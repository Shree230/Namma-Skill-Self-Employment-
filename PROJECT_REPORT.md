# Project Report: Namma-Skill

## Introduction
Namma-Skill is an Android application created to support Skill India and self-employment goals. The app helps rural youth discover vocational courses and apply to nearby training centers.

## Problem
Many small-town and village youth do not receive timely information about skill development batches. They miss short-term training opportunities and lose chances to become job-ready.

## Proposed Solution
The application provides a single platform where users can search vocational courses, filter by duration, locate centers, view eligibility, and apply directly.

## App Usage Flow
Open app → Select Course Finder → Apply filters → View course details → Tap Apply → Candidate summary is generated → Sent to center.

## GenAI Usage
GenAI is used for:
- Smart course recommendations
- AI chat support
- Candidate summary generation
- Smart notification messages
- Multilingual support concept

## Android Studio Implementation
The project uses Kotlin and Jetpack Compose. Screens are divided into Home, Course Finder, Center Map, and AI Chat Assistant. Firebase and Google Maps can be connected during full implementation.

## Impact Goals
- Bridge the gap between training infrastructure and rural youth.
- Reduce unemployment by promoting job-ready courses.
- Provide equal opportunity for village youth.
